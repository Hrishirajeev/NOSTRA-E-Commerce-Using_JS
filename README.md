# NOSTRA

A responsive fashion e-commerce website built using **HTML, Tailwind CSS, and JavaScript**.

## Features

- Responsive navigation bar
- Promotional signup banner
- Image slider / advertisement carousel
- Dark overlay effect on banner images
- Product cards
- Most Wanted horizontal carousel
- Left and right product scrolling
- Product tags for gender, color, and occasion
- Search functionality
- Product filtering
- Clear All functionality
- Responsive design using Tailwind CSS
- Contact Us page
- Collections page

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript
- SVG Icons

## JavaScript Functionality
